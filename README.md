> 클론했다면 형제 폴더에 `_shared` 를 두세요: `<작업폴더>\WindBotDeckImageAndroid` + `<작업폴더>\_shared\DeckImageSkia\DeckImageSkiaRenderer.cs`
> (배포 백업 ZIP 에는 `_shared/` 가 들어 있어 그대로 풀면 바로 빌드됩니다.)
