  EDOPro 덱 이미지 (Android)  v1.8
  com.hellzgate.windbotdeckimage
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 유희왕 덱 파일(.ydk)과 카드 이미지를 합쳐,
 덱 리스트를 한 장의 이미지로 만들어 주는 안드로이드 앱입니다.
 (PC 판 EdoProDeckImage 와 같은 렌더러·같은 결과)


■ 1. 설치

  ① apk 파일을 폰으로 옮깁니다.
     (USB · 카카오톡 나에게 보내기 · 구글 드라이브 등 아무 방법이나)

  ② 폰의 파일 관리자에서 apk 를 눌러 설치합니다.
     "출처를 알 수 없는 앱 설치" 를 허용해야 합니다.
     (설정 → 앱 → 특정 앱 → 알 수 없는 앱 설치 허용)

  ③ 바탕화면에 "EDOPro 덱 이미지" 아이콘이 생깁니다.

  ※ 서명은 개발용(디버그 키)입니다. Play 스토어 배포용이 아닙니다.
  ※ Android 7.0(API 24) 이상에서 동작합니다.


■ 2. 준비 (한 번만)

  카드 이미지가 폰에 있어야 합니다.

  · EDOPro 를 폰에서 쓰고 있다면 이미 받아 둔 이미지가 있습니다.
    (보통 Android/data/<EDOPro 패키지>/files/pics 또는 Download 폴더)
  · 없으면 PC 의 D:\edopro\pics 에서 필요한 카드만이라도 복사해 두세요.
    (파일 이름이 <카드ID>.jpg 이어야 합니다. 예: 10000010.jpg)

  ※ 폴더 전체(약 490MB, 1만 9천 장)를 넣어도 되고,
     자주 쓰는 덱의 카드 몇십 장만 넣어도 됩니다.


■ 3. 사용 순서 (v1.1)

  ①  [덱 열기]  →  .ydk 파일 선택
  ②  [카드 이미지]  →  pics 폴더를 선택 (한 번 고르면 다음부터 기억합니다)
      · 처음 고를 때 카드 장수를 세느라 몇 초 걸릴 수 있습니다.
  ③  아래 옵션을 바꾸면 미리보기가 자동으로 다시 그려집니다.
  ④  [저장]  →  사진첩 Pictures/WindBotDeckImage 에 PNG 로 저장됩니다.


■ 4. 옵션

  카드 폭       60 ~ 200 (기본 110) — 키우면 섹션 글씨도 함께 커집니다
  열            한 줄에 몇 장 (6 / 8 / 10 / 12, 기본 10)
  테마          다크(남색) / 라이트(흰색)
  x2/x3         같은 카드는 1장만 보여주고 장수를 배지로 표시 (이미지가 짧아짐)
  사이드        사이드 덱 포함/제외
  제목          맨 위 제목 (비우면 덱 파일 이름)


■ 5. 알아둘 점

  · 카드 이미지가 없는 카드는 회색 칸에 "?카드ID" 로 표시됩니다.
    → EDOPro 에서 이미지를 받았거나 pics 폴더에 넣으면 정상 표시됩니다.

  · 미발매 카드 이미지에는 EDOPro 원본에 이미 SAMPLE 워터마크가 있습니다.

  · 선택한 폴더/덱은 앱에 기억됩니다(권한 유지). 폴더를 옮기면 다시 골라야 합니다.

  · 아주 큰 이미지(카드 폭 200 + 12열)는 저사양 폰에서 느릴 수 있습니다.


■ 6. PC 판과의 차이

  · PC 판(WindBotDeckImage.exe): 폴더 일괄 변환 · PNG/JPG 선택 · 미리보기 창
  · Android 판: 한 덱씩 저장 · PNG 고정 · 사진첩 자동 저장
  · 렌더링 결과(레이아웃·색·글씨 크기)는 같습니다.

■ 7. 폴더가 인식되지 않을 때 (v1.1)

  안드로이드 저장소 제한 때문에 [카드 이미지] 로 고른 폴더가
  "카드 0장" 으로 보이는 기기가 있습니다. 이때는 두 가지 방법이 있습니다.

  (A) 경로 모드  ← 가장 쉬움
     1) 화면 맨 아래 안내줄("폴더가 인식되지 않으면 여기를 누르세요")을 누릅니다.
     2) [모든 파일 액세스] 버튼 → 설정에서 이 앱을 허용 → 뒤로 가기
     3) 경로 칸에  /sdcard/EDOPro/pics  가 들어 있는지 확인하고 [이 경로로 읽기]
     ※ 한 번 설정하면 다음부터는 자동으로 이 경로를 씁니다.

  (B) 이미지 ZIP
     1) PC 에서 pics 폴더를 zip 으로 만듭니다(전체 또는 필요한 카드만).
     2) 폰으로 옮긴 뒤 앱에서 [이미지 ZIP] → 그 zip 선택.
     ※ zip 안의 폴더 구조는 상관없습니다. 파일 이름이 <카드ID>.jpg 이면 됩니다.

  두 방법 모두 안 되면 adb 로그로 원인을 볼 수 있습니다.
     adb logcat -s AI-EDITOR
■ 8. 지인에게 줄 때 (그 폰에 카드 이미지가 없을 때)

  이 앱은 폰에 있는 카드 이미지(EDOPro pics)만 쓸 수 있습니다.
  상대 폰에 EDOPro 이미지가 없으면 카드가 전부 "?ID" 로만 보입니다.

  이때는 **그 덱에 쓰인 카드만** 담은 ZIP 을 만들어 주면 됩니다(약 2~3MB).

   PC 에서 (에디터 폴더 기준):
     powershell -NoProfile -ExecutionPolicy Bypass -File _tools\deck-pics-zip.ps1 ^
       -Ydk "받은덱.ydk" -Out "그덱-pics.zip"

   → 폰으로 전송(카톡/드라이브) → 앱에서 [이미지 ZIP] → 그 zip 선택.
   ※ zip 안 구조는 상관없고, 파일 이름이 <카드ID>.jpg 이기만 하면 됩니다.
   ※ 상대가 EDOPro 를 폰에서 쓴다면, 앱이 [모든 파일 액세스] 허용 후 pics 폴더를 자동으로 찾습니다.
■ 9. 카드 이미지가 일부만 나올 때 (v1.4 — 인터넷 자동 보완)

  안드로이드 EDOPro 는 카드 이미지를 **화면에 띄울 때 그때그때 내려받아** pics 폴더에 쌓습니다.
  그래서 EDOPro 에서 그 덱을 한 번도 열지 않았다면, 앱에서 볼 때 그 카드들의 이미지가 없습니다.
  (카드ID 매칭 문제가 아니라 **파일이 아직 없는 것**)

  v1.4 부터는 앱이 **없는 카드만 인터넷에서 자동으로 받아** 캐시에 저장합니다.
   · 첫 로딩에만 잠깐 걸리고(예: 23장 ≈ 1.2초), 다음부터는 캐시에서 즉시 읽습니다.
   · **커스텀/프록시 카드**(공식 DB에 없는 ID)는 받을 수 없습니다 → 그 카드는 경로 모드나 ZIP 을 쓰세요.
   · 인터넷이 없으면 자동으로 건너뜁니다(오류 없음).
■ 10. 로딩 창 (v1.5)

  카드 이미지를 인터넷에서 받을 때는 **가운데 로딩 창**이 뜹니다.
     "카드 이미지 준비  ·  이미지 내려받는 중…  15 / 17"  + 진행 막대
  다 받으면 자동으로 닫히고 그림이 완성됩니다.
  ZIP 을 열 때는 "ZIP 압축을 푸는 중…" 창이 뜹니다(큰 파일은 오래 걸립니다).
■ 11. 저장 위치 (v1.6~)

  앱이 만드는 파일은 **앱 전용 폴더**에 모입니다(파일 관리자에서 보입니다).
     /sdcard/Android/data/com.hellzgate.windbotdeckimage/files/
        · pics-cache\      인터넷에서 받은 카드 이미지 (다음부터 재사용)
        · logs\app.log     오류/시작 로그 (1MB 넘으면 app.log.old)
        · (이미지 ZIP 등 직접 넣은 파일은 여기에 두면 편합니다)

  · 예전에는 '캐시' 폴더를 썼는데, 시스템이 비울 수 있어서 앱 폴더로 옮겼습니다.
  · 설정은 앱 내부(Settings)에 저장됩니다.

■ 12. v1.8 — 이름 변경 + 이미지 폴백 강화 (2026-11-08)

  · 앱 이름: "덱 이미지" → **"EDOPro 덱 이미지"**
    (패키지 이름은 그대로 com.hellzgate.windbotdeckimage — 기존 앱 위에 덮어 설치됩니다)

  · **이미지 찾는 순서** (PC 판 v1.3 과 같음)
      ① 폰의 이미지 폴더(여러 곳) → ② 인터넷 캐시
      ③ 같은 카드 ID      : YGOPRODeck (cards → cards_small → cards_cropped)
      ④ 카드 DB의 원본 ID : 재록·다른 일러는 원본 그림으로 (예: 17242023 → 17242022)
      ⑤ 카드 DB의 영문 이름으로 검색 → 그 카드 그림
      ⑥ Yugipedia (마지막 수단)
      ⑦ 그래도 없으면 그 카드만 빈 칸

  · **카드 DB(cdb) 내장**: cards.cdb / cards-en.cdb 를 앱에 넣어 두어
    폰에 EDOPro 카드DB가 없어도 ④⑤ 가 동작합니다.
    (기기 EDOPro 폴더가 있으면 그 cdb 도 함께 씁니다 — 첫 실행 때 files/cdb 로 1회 복사)

  · **여러 이미지 폴더 동시 사용**
      경로 칸에 세미콜론(;)으로 여러 폴더를 적을 수 있습니다.
      예) /sdcard/EDOPro/pics;/sdcard/Download/pics
      [카드 이미지] 창에 "찾은 폴더 N곳 모두 사용" 항목이 추가되었습니다.

  · 다운로드: 404 는 다음 후보 · 일시 오류는 3회 재시도 · HTML 오류 페이지는 저장하지 않음
